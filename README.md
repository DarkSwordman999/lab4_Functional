### Средняя №10. Несколько функций через `map`

- `apply_each(functions, values)` применяет **каждую** функцию ко всему списку через `map` и возвращает словарь `{имя функции: результаты}`. Например, `apply_each([abs, str], [-1, 2])` возвращает `{'abs': [1, 2], 'str': ['-1', '2']}`.
- `apply_chain(functions, values)` применяет функции **цепочкой**: каждый следующий `map` получает результат предыдущего. `apply_chain([f, g], xs)` равно `[g(f(x)) for x in xs]`. Благодаря ленивости `map` промежуточные списки не создаются.
- `map_pairwise(func, a, b)` — `map` с функцией двух аргументов по двум спискам.

### Средняя №2. Фильтрация чётных

`filter_even` вызывает `filter(is_even, numbers)` с именованной функцией-предикатом. Корректно работает с нулём и отрицательными числами.

### Средняя №8. Декоратор `@timed`

Замеряет время через `time.perf_counter()` и выводит строку `имя выполнена за N с`. Время последнего вызова сохраняется в атрибуте `func.last_time`, поэтому его можно проверить в тестах. Замер стоит в блоке `finally`, так что время фиксируется даже при исключении. `functools.wraps` сохраняет имя и документацию исходной функции.

### Повышенная №10. Собственный `reduce`

`my_reduce(function, iterable, initial)` повторяет поведение `functools.reduce`:

- свёртка идёт слева направо: `my_reduce(f, [a, b, c])` равно `f(f(a, b), c)`;
- работает с любым итерируемым объектом, в том числе с генератором, потому что использует `iter()` и `next()`, а не индексы;
- `initial` может быть любым значением, включая `None`. Чтобы отличить «не передано» от `None`, используется объект-маркер `_NO_INITIAL`;
- на пустой последовательности без `initial` выбрасывается `TypeError`, как в стандартной библиотеке.

Тесты сравнивают результат с `functools.reduce` на нескольких функциях. Отдельно есть рекурсивный вариант `my_reduce_recursive`.

### Повышенная №3. Карринг

`curry(f)` превращает `f(a, b, c)` в цепочку вызовов: `curry(f)(a)(b)(c)`. Аргументы можно передавать и группами: `curry(f)(a, b)(c)`. Число обязательных аргументов определяется через `inspect.signature` (параметры со значениями по умолчанию не учитываются), для `*args` его можно задать явно: `curry(func, arity=3)`. Промежуточные функции можно сохранять и переиспользовать: `add_10 = curry(add3)(10)`. Реализация построена на замыканиях: каждый шаг запоминает уже собранные аргументы.
